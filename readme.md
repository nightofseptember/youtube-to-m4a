🏴‍☠️This is just an very simple script to make it easier to download YT Videos in m4a-formatand making it usable by most DAP's. 🏴‍☠️
 - It downloads it as M4A and the PNG, NOT VIDEO. 

Requirements: You need to download FFMPEG, ffprobe, ffmpeg and yt-dlp

1. First download ffmpeg and yt-dlp and put them into a folder called "ytfiles"
    - https://github.com/BtbN/FFmpeg-Builds/releases , https://github.com/yt-dlp/yt-dlp

3. Create a txt/notepad file, and ctrl + v into there.
   
4. then save it as "xyz.bat" and "all files" in filetype. 
   info - xyz can be whateve
   
5.  then you should be able to run it and just follow the instructions.
